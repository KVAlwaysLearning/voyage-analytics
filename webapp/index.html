Where should this traveller stay?

Suggestions use the traveller's booking history and what similar travellers booked. The hotel in the city they fly from is never suggested.

    Choose a traveller and a departure city to see suggestions. Traveller IDs run from 0 to 1339.

    What does a first name suggest?

    The gender model reads letter patterns in a first name. It is right about 56% of the time across three classes, and 86% of the time for male vs female, so treat it as a rough estimate for analytics, never as a fact about a person.

    Enter a name to see the probability of each label.

    The models behind this page

    Each model is tracked in MLflow on DagsHub, registered, packaged in one Docker image and served by a Flask API.

    How a prediction reaches you

    1. ColabExploration, training and tuning
    2. MLflow on DagsHubEvery run logged, best models registered
    3. Flask APIValidates input and serves all three models
    4. DockerOne image, pushed to Docker Hub
    5. Render and KubernetesPublic hosting and scaling
    6. This pageCalls the API from your browser
